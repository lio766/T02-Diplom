# Raumbuchungssoftware – Frontend (Vue 3 + Vite)

Dieses Frontend wurde mit Vue 3 und Vite erstellt und enthält eine einfache Landing Page.

## Voraussetzungen
- Node.js (empfohlen: v18+ oder aktueller)
- npm

## Entwicklung starten
```bash
npm install
npm run dev
```
Der Dev-Server zeigt Ihnen die URL (z. B. http://localhost:5173).

## Produktion bauen
```bash
npm run build
```
Die gebauten Dateien liegen unter `dist/`.

## Vorschau der Produktion
```bash
npm run preview
```

## Struktur
- `src/App.vue`: Landing Page mit Hero, Features und CTA.
- `index.html`: Dokumenttitel und Meta-Beschreibung.
